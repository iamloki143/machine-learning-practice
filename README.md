# Machine Learning Practice

Hands-on Machine Learning exercises completed during a one-week
Generative AI course.

## Topics Covered

- Linear Regression
- Support Vector Regression (SVR)
- Decision Tree Regression
- Random Forest Regression
- Boosting: AdaBoost, Gradient Boosting and XGBoost
- Grid Search and Hyperparameter Tuning

## Additional Projects

- Profit Prediction
- Salary Prediction

## Repository Contents

Each topic folder contains Jupyter notebooks, datasets, Python scripts
and, where applicable, saved models and evaluation results.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook
